# Project Overview

## Introduction

The Ride Sharing Application is a Low-Level Design (LLD) project built using Java.

The objective of the system is to provide ride booking functionality where passengers can request rides and the system automatically assigns the nearest available driver.

The project is designed using SOLID Principles and Design Patterns to ensure maintainability, scalability, and extensibility.

---

## Business Problem

Traditional taxi booking systems require efficient driver allocation, fare calculation, and ride lifecycle management.

The system should:

- Match nearest drivers.
- Support multiple vehicle types.
- Calculate fares dynamically.
- Notify users of ride updates.
- Support future business requirements.

---
